# University Management Database

Проект представляет собой базу данных для хранения и организации информации об университете. Предметная область включает университеты, ректоров, преподавателей, студентов и учебные дисциплины, а также связи между ними.
База данных решает задачу хранения сведений о структуре университета и учебном процессе: позволяет определить, к какому университету относятся студенты и преподаватели, кто является ректором, какие дисциплины ведут преподаватели и какие дисциплины изучают студенты.
